# Hiren Vasavishetti | Portfolio

## Features

- **Interactive UI** – Smooth hover effects and scroll reveal animations
- **Project showcase** – Expandable project cards with detailed case studies in a modal overlay
- **Skills section** – Finance, technical and analytical skills
- **Responsive** – Clean layout across desktop, tablet and mobile

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Projects Featured

- **Acquisition Financing Simulator** – Python and SQLite dashboard exploring acquisition funding, debt capacity and liquidity risk
- **PepsiCo / Celsius M&A Valuation** – Independent Excel valuation and hypothetical acquisition analysis, with a downloadable model and pitch book

## Running Locally

1. Clone the repository:

   ```sh
   git clone https://github.com/hirenvasavishetti/hirenvasavishetti.github.io.git
   cd hirenvasavishetti.github.io
   ```

2. Install dependencies and start the development server (Node.js 22 and pnpm 10):

   ```sh
   pnpm install
   pnpm dev
   ```

3. Open `http://127.0.0.1:5173` in your browser.
